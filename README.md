# Task 6: Host a Static Website with GitHub Pages

## Project Overview
This project demonstrates how to create and deploy a static website using GitHub Pages as part of my DevOps Internship Task 6.

## Technologies Used
- HTML5
- CSS3
- Git and GitHub
- GitHub Pages

## Features
- Simple and responsive webpage
- Custom CSS styling
- Centered content with a white card layout
- Blue heading and light gray background
- Free hosting using GitHub Pages

## Project Structure
```text
static-website-task6/
├── index.html
└── README.md
```

## Deployment Steps
1. Created an `index.html` file with HTML and CSS.
2. Initialized a Git repository.
3. Committed the project files.
4. Pushed the code to GitHub.
5. Enabled GitHub Pages from the `main` branch and root folder.
6. Verified the published website.
